# resume-builder

> 一个帮你快速生成一页纸中文求职简历的 AI Skill（.docx 输出，专业配色、紧凑单页）。

## 它做什么

把你的姓名/电话/学校/项目/比赛/链接，一次性喂给 AI，它直接给你一份**排好版的 Word 简历**：

- 深藏青专业配色（#1F3A5F），不是花里胡哨的模板风
- 页首一寸证件照 + 线上简历二维码
- 模块标题左竖杠、时间右对齐、奖项小标签、灰底自我评价框
- 一页排满，不溢出、不素色、无外框
- 按岗位自动调模块顺序（销售/产品/开发/通用）
- S/T/A/R 比赛文案、S/A/R 项目文案

## 为什么做这个

每次让 AI 做简历都是开盲盒——这次好看下次丑，配色随机、间距随机、照片位置随机。这个 Skill 把一套调过 N 版的版式参数和文案规范固化下来，下次直接复用，不再靠运气。

## 怎么用

1. 把这个 Skill 文件夹丢进你的 AI 工作区（`.user_skills/` 或对应 Skill 目录）。
2. 跟 AI 说："帮我做一份简历，岗位是 XX，我叫 XX，电话 XX……"
3. AI 会读 `SKILL.md` → `references/layout-spec.md` → `references/content-rules.md`，按规范生成 .docx。

## 目录结构

```
resume-builder/
├── SKILL.md              # AI 入口（触发条件+工作流+硬底线）
├── references/
│   ├── layout-spec.md    # 版式硬参数（颜色/字体/间距/页首/奖项/自我评价）
│   └── content-rules.md  # 内容规范（模块顺序/写法/注意事项）
└── assets/               # 放一寸照片和线上简历二维码
```

## 适配岗位

- 销售/BD（一页紧凑版）
- AI 产品经理
- AI 应用开发
- 数据分析/通用岗
